# AI-Powered Healthcare Diagnosis Assistant

An academic machine learning web application that predicts a possible disease based on symptoms entered by the user.

> ⚠️ **Disclaimer:** This project is an academic prototype for educational purposes only. It is not a medical diagnosis tool and should not be used as a substitute for professional medical advice.

---

## 📌 Project Overview

The **AI-Powered Healthcare Diagnosis Assistant** uses Natural Language Processing (NLP) and Machine Learning to analyze user-provided symptoms and predict a possible disease category.

The project provides a simple web interface where users can enter their symptoms and receive a prediction generated by the trained machine learning model.

---

## 🚀 Features

- Enter symptoms using natural language
- Text preprocessing using TF-IDF
- Disease prediction using Logistic Regression
- Simple and user-friendly web interface
- Flask-based backend
- Prediction result displayed through a web page
- Academic healthcare prototype

## 🤖 Machine Learning Approach

The project follows these main steps:

1. Load the symptom-disease dataset
2. Clean and preprocess the text data
3. Convert symptom descriptions into numerical features using **TF-IDF**
4. Train a **Logistic Regression** classification model
5. Save the trained model using Joblib
6. Load the trained model in the Flask application
7. Accept symptoms entered by the user
8. Predict the corresponding disease category
